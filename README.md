# 🚌 Bus Booking Management System
A Bus Booking Management System built using Python, Pandas, and Streamlit to manage bus bookings, customer information, booking status, payments, ratings, and operational analytics through an interactive web application.
## Business Problem

Bus operators need an efficient way to manage booking information and understand customer and operational trends.
This project helps organize booking data and provides analytical insights into:

Total bookings
Revenue generated
Passenger volume
Seat occupancy
Booking status
Cancellation trends
Popular routes
Bus operator performance
Customer ratings
Payment methods
Peak-hour bookings
